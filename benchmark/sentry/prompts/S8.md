The workflow engine's metric alert detector is failing at instantiation:

```
TypeError: Can't instantiate abstract class MetricAlertDetectorHandler with abstract method build_occurrence_and_event_data
```

After a recent refactor, `MetricAlertDetectorHandler` was changed to extend `StatefulDetectorHandler` instead of the base `DetectorHandler`. However, `StatefulDetectorHandler` declares `build_occurrence_and_event_data()` as an abstract method, and `MetricAlertDetectorHandler` doesn't implement it.

This means no metric alerts can be processed — the handler can't be created at all.

Please find and fix the missing abstract method implementation.
