Our span flusher process management is crashing intermittently during shutdown or when a flusher child process exits unexpectedly:

```
ProcessLookupError: [Errno 3] No such process
```

or sometimes:

```
OSError: [Errno 3] No such process
```

The error happens when the parent process tries to send a signal (via `os.kill()`) to a flusher child process that has already terminated. This is a race condition — the process exits between the time we decide to signal it and the actual `kill()` call.

The crash disrupts the shutdown sequence and can leave other flusher processes orphaned.

Please find and fix the root cause in the span flusher process management code.
