Our uptime consumer crashes during graceful shutdown on Python 3.12:

```
AttributeError: 'Queue' object has no attribute 'shutdown'
```

The traceback points to the shutdown path in the queue-based consumer. The code tries to call `queue.shutdown()` on a standard `queue.Queue` instance, but this method doesn't exist in our Python version.

This blocks clean process termination — the consumer hangs on shutdown and has to be killed with SIGKILL, which risks data loss from unprocessed messages still in the queue.

Please find and fix this compatibility issue.
