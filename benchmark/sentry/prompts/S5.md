Our integration sync system is failing when dispatching Celery tasks for outbound assignment synchronization:

```
TypeError: Object of type datetime is not JSON serializable
```

The error occurs when we try to pass assignment source data through Celery task kwargs. The `queued` field in the serialized assignment source dict is a `datetime` object, which the default JSON serializer cannot handle.

This breaks the entire outbound sync pipeline — when a user assigns an issue in Sentry, the assignment never propagates to the external integration (e.g., Jira, GitHub Issues).

The serialization code converts the assignment source to a dict but doesn't convert the datetime to a string format.

Please find and fix the root cause.
